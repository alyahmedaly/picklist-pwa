# How Portion-aware scoring works (simple + fair)

We keep **AliScore V2** for everyday foods (per 100 g/ml, percentile-based), and add **CategoryScores** that judge items by a **realistic serving** for that category. Each CategoryScore ranks **within its category** so chocolate isn’t compared to broccoli.

## Steps per category

1. **Pick a standard serving** (e.g., chocolate **10 g**, nuts **15 g**, skyr **200 g**, tuna **120 g**, oil **5 ml**).
2. Convert label data (per 100 g/ml) → **per-serving**.
3. Compute **percentile ranks within the category**:

   * “Good” ↑: **protein**, **fiber** (higher → better)
   * “Bad” ↓: **kcal**, **sugar**, **sat fat**, **salt** (lower → better)
4. Weighted sum → **CategoryScore (0–99.9)**, with a tiny tie-breaker (favoring ↑protein/fiber, penalizing sugar/sat-fat).
   *Nobody hits 100, so sorting is meaningful.*

  Core Functions (aliFilters.ts)

  export function filterHalalOnly(products: Product[]): Product[] {
    return products.filter(p => p.halalCheck?.status === 'halal');
  }

  export function filterHighProtein(products: Product[], minScore = 70): Product[] {
    return products.filter(p =>
      p.proteinOptimization?.proteinDensityScore >= minScore
    );
  }

  export function filterPostWorkout(products: Product[], minScore = 80): Product[] {
    return products.filter(p =>
      p.postWorkoutOptimization?.postWorkoutScore >= minScore
    );
  }
